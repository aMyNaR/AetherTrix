# 🟢 AetherTrix v2.1.2

### 🚀 کلاینت سریع و خصوصی VPN برای اندروید

AetherTrix یک کلاینت VPN سریع و متمرکز بر حفظ حریم خصوصی برای اندروید است؛ با طراحی الهام‌گرفته از **Omnitrix**، رابط کاربری کاملاً مشکی، جزئیات سبز نئونی و صفحه شروع متحرک اختصاصی.

این پروژه بر پایه هسته متن‌باز **Aether** ساخته شده است و از **MASQUE، WireGuard و WARP-in-WARP** پشتیبانی می‌کند. قابلیت **Smart Connect** نیز به‌صورت خودکار پروتکل‌ها را بررسی کرده و سریع‌ترین مسیر پایدار را انتخاب می‌کند.

---

## ✨ ویژگی‌ها

| قابلیت | توضیحات |
|---|---|
| 🔐 تونل رمزگذاری‌شده | MASQUE (HTTP/3 QUIC)، WireGuard و WARP-in-WARP با انتخاب خودکار یا دستی |
| ⚡ Smart Connect | آزمایش زنده پروتکل‌ها و انتخاب سریع‌ترین گزینه قابل اعتماد |
| 🧩 Split Tunneling | انتخاب دقیق برنامه‌هایی که از VPN استفاده کنند |
| 🛡️ محافظت DNS | انتقال DNS داخل تونل VPN با استفاده از Cloudflare 1.1.1.1 |
| 🚨 Kill Switch | در صورت قطع شدن تونل، ترافیک مسدود می‌شود |
| 🔄 اتصال مجدد خودکار | بازیابی اتصال پس از مشکلات موقت شبکه |
| 📱 تنظیمات سریع | اتصال و قطع اتصال از بخش اعلان‌های اندروید |
| 🌙 پوسته Omnitrix | طراحی مشکی و سبز نئونی، فونت تک‌فاصله و گوی اتصال متحرک |
| 🌐 زبان‌ها | پشتیبانی از فارسی و انگلیسی |

1. 📥 فایل `AetherTrix-v2.1.2-Android-Universal.apk` را دانلود کنید.

## ⚠️ نکته مهم

در اولین نصب، **Google Play Protect** ممکن است هشدار «توسعه‌دهنده ناشناس» نمایش دهد.

این موضوع برای برنامه‌هایی که خارج از Play Store و با کلید شخصی امضا شده‌اند طبیعی است.

فایل APK با یک **کلید انتشار اختصاصی** امضا شده و هر نسخه دارای **چک‌سام SHA-256** برای بررسی اصالت است.

نسخه‌های آینده که با همان کلید امضا شوند، به مرور اعتماد بیشتری از Play Protect دریافت خواهند کرد.
